# gdViewer

**gdViewer** is a JBrowse 2 plugin designed for interactive visualization and exploration of genomic diversity. It integrates genomic variants, phylogenetic relationships, motif predictions, and haplotype information into a unified genome browser interface.

> **Development Status**
>
> gdViewer is currently under active development.
>
> The latest development code is available in the [`dev`](../../tree/dev) branch. The `main` branch is not yet intended for general use.

Features, documentation, and installation instructions will be added as development progresses.
